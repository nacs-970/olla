After the prompt loop: `total = len(FIXED_PROMPTS)`; `compliance_pct = results["compliant"] / total * 100`; print a line in the form `f"{model} (think={think_mode}): {compliance_pct:.0f}% compliant ({results['compliant']}/{total}), {results['reverted_to_native_format']} reverted to native format, {results['non_compliant']} non-compliant"`.
