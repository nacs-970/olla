# Phase 02.1: API connect with olla, not just ollama now - Context

**Gathered:** 2026-09-04
**Status:** Ready for planning

<domain>
## Phase Boundary

Enable `olla` to connect to remote LLM APIs using an OpenAI-compatible interface with OpenRouter as the primary preset, alongside local Ollama.
Delivers model dispatch, API authentication, request streaming with stop-tag buffering, and error handling.
Does not change core ReAct loop semantics, prompt XML formatting, or safety gate mechanisms.

</domain>

<decisions>
## Implementation Decisions

### Provider Architecture & Transport
- **D-01:** Implement an OpenAI-compatible HTTP client using `httpx` to target OpenRouter (`https://openrouter.ai/api/v1`) as the primary gateway, with custom `--base-url` override for arbitrary OpenAI-compatible endpoints. — **Reversibility:** costly — Defines provider request layer and dependency profile.
- **D-02:** Use token streaming for API responses to print generation in real-time, buffering tokens locally to prevent leaking `</args>` stop sequence tags to stdout. — **Reversibility:** reversible — Internal stream reader behavior.

### Auth & Configuration
- **D-03:** Read API keys from environment variables (`OPENROUTER_API_KEY`, `OPENAI_API_KEY`) with optional CLI override via `--api-key`. — **Reversibility:** reversible — Standard CLI/env auth precedence.
- **D-04:** Use prefix syntax in `--model` to route providers (e.g. `openrouter/meta-llama/llama-3.1-70b-instruct`, `openai/gpt-4o-mini`). Models without prefixes default to local Ollama. — **Reversibility:** costly — CLI UX and model dispatch contract.
- **D-05:** Support custom endpoint override via `--base-url` flag and `OPENAI_BASE_URL` environment variable. — **Reversibility:** reversible.
- **D-06:** Fail fast on missing API key with a clear diagnostic message and non-zero exit code (no interactive prompts). — **Reversibility:** reversible.

### Request Contract & Stream Handling
- **D-07:** Pass `"stop": ["</args>"]` in API payload while maintaining a client-side stream buffer window to halt terminal streaming when `</args>` is encountered. — **Reversibility:** reversible.
- **D-08:** Pull context length and limits dynamically from model detail metadata or provider endpoints where available. — **Reversibility:** reversible.
- **D-09:** Configure 60s request timeout with automatic exponential retries on HTTP 429 and 5xx errors (up to 3 retries). — **Reversibility:** reversible.
- **D-10:** Display reasoning tokens (`<think>...</think>`) in dimmed terminal styling, evaluating tool tags strictly outside thinking blocks. — **Reversibility:** reversible.

### Ollama Coexistence & Code Architecture
- **D-11:** Extract provider backends into `src/olla/providers/` (`ollama.py`, `openai_compat.py`) exposing a unified chat interface, decoupling `loop.py` from client specifics. — **Reversibility:** costly — Core code refactor.
- **D-12:** Extend `--smoke-test` to support both local Ollama and remote API models via the unified provider layer. — **Reversibility:** reversible.
- **D-13:** Format remote API errors as clean diagnostics without Python stack traces (e.g. `OpenRouter error (401): Invalid API key`). — **Reversibility:** reversible.

### the agent's Discretion
- In-memory vs disk caching for OpenRouter model metadata (the agent will implement efficient lightweight caching).
- Exact stream window buffer size for stop sequence detection.

</decisions>
