<objective>
Close UAT gap G-03-4 without depending on a larger model: make full-file edits to existing targets a read-derived, freshness-checked operation whose actual proposed change is visible before confirmation.

**As a** user running an agentic task with olla, **I want to** inspect and safely update an existing project file, **so that** a weak local model cannot turn a path-only approval into an unrelated blind overwrite.

Purpose: The UAT failure is AND-gated. A small model selected an invalid write-before-read plan, and the runtime accepted it because the prompt and confirm gate had no edit contract. This plan closes both actionable sides: it teaches the intended edit sequence and enforces model-independent overwrite invariants in `run_loop` while preserving the deliberately simple full-file `write_file(path, content)` interface.

Output: guarded file-edit dispatch and useful write previews in `src/olla/loop.py`, a concise edit transcript in `src/olla/prompts.py`, and focused regressions in `tests/test_loop.py` and `tests/test_prompts.py`.
</objective>
