Purpose: Complete MEM-01 without altering the existing shell/file teaching or execution logic and without expanding into persistence or compaction.

Output: parser/prompt contract tests, complete normal/dry-run loop integration tests, and a green full maintained suite.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Model `<args>` -> protocol parser | Whitespace and note content are untrusted but semantically significant. |
| Memory call -> terminal/history | A write acknowledgment may identify a key but must not disclose its stored value. |
| Dry-run -> scratchpad | Preview is observational only and cannot read or mutate state. |
| One run -> later run | In-process state must be destroyed at invocation completion. |
