- Task 3: Fix WR-01 dead-code gap in `src/olla/loop.py` (~lines 55-60). Current:
  ```python
  if "error" in result:
      combined = result["error"]
  elif "stdout" in result or "stderr" in result:
      combined = result.get("stdout", "") + result.get("stderr", "")
  else:
      combined = "(no output)"
  ```
  `run_shell` always returns `stdout`/`stderr` keys (possibly `""`) on success, so the `elif` is always true and `(no output)` never fires. Fix to check truthiness:
  ```python
  if "error" in result:
      combined = result["error"]
  else:
      combined = result.get("stdout", "") + result.get("stderr", "")
      if not combined:
          combined = "(no output)"
  ```
  Add/update test for a real no-output success (e.g. `touch <tmpfile>` -> `Observation: (no output)`).
