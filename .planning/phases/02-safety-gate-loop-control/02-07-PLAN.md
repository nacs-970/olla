This is a sibling equivalent-form bypass of the SAME rule (7) that `02-06` just hardened for round-3 CR-02 (`//`, `///`, `--recursive ... //`): rule (7)'s root-target detection does not recognize dot-segment equivalent forms of `/` — `/.`, `//.`, `/./` — all of which `os.path.normpath()` and the Linux kernel resolve identically to `/` (or `//`, which Linux treats identically to `/`). `chmod -R 777 /.` therefore returns CONFIRM, not BLOCK, even though it recursively chmods the entire root filesystem exactly as `chmod -R 777 /` does — and chmod/chown have NO `--preserve-root` default (unlike GNU `rm`).
