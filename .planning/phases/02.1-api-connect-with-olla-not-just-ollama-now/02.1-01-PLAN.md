## Phase Goal

Enable olla to connect to remote LLM APIs using an OpenAI-compatible interface with OpenRouter as the primary preset, alongside local Ollama.

</objective>

<title>Task 2: Implement OpenAICompatProvider with streaming, stop buffer, and retries</title>
<read_first>
- src/olla/providers/base.py
- .planning/phases/02.1-api-connect-with-olla-not-just-ollama-now/02.1-CONTEXT.md
- .planning/phases/02.1-api-connect-with-olla-not-just-ollama-now/02.1-RESEARCH.md
</read_first>
<action>
1. Create `src/olla/providers/openai_compat.py`:
   - Implement `stream_with_stop_buffer(iterator, stop_seq="</args>")` yielding `StreamChunk`. Hold back characters matching any prefix of `stop_seq` until confirmed, then stop iteration when `stop_seq` matches.
   - Implement `OpenAICompatProvider` with `__init__(self, model: str, api_key: str, base_url: str, timeout: float = 60.0)`.
   - In `stream_chat`:
     - Set headers: `Authorization: Bearer <api_key>`, `HTTP-Referer: https://github.com/olla/olla`, `X-Title: olla CLI Agent`, `Content-Type: application/json`.
     - Set payload: `model: self.model`, `messages: messages`, `stop: ["</args>"]`, `stream: True`.
     - Request `POST {self.base_url}/chat/completions` with `httpx.Client(timeout=self.timeout)`.
     - Retry up to 3 times on HTTP 429 or 5xx with exponential backoff (`1s`, `2s`, `4s`).
     - On non-retryable error, raise `ProviderError(f"OpenRouter error ({status}): {error_text}")`.
     - Parse SSE lines `data: {"choices": [{"delta": {"content": "...", "reasoning": "..."}}]}`.
     - Detect `<think>` tags and reasoning delta, setting `is_thought=True`.
   - In `chat`: accumulate text from `stream_chat`.
2. In `src/olla/providers/__init__.py`:
   - Implement `get_provider(model: str, api_key: Optional[str] = None, base_url: Optional[str] = None, timeout: float = 60.0) -> tuple[Provider, str]`.
   - If `model.startswith("openrouter/")`: model_id = `model[len("openrouter/"):]`, default `base_url = "https://openrouter.ai/api/v1"`, key from `api_key` or `OPENROUTER_API_KEY`.
   - If `model.startswith("openai/")`: model_id = `model[len("openai/"):]`, default `base_url = "https://api.openai.com/v1"`, key from `api_key` or `OPENAI_API_KEY`.
   - If `model.startswith("ollama/")`: model_id = `model[len("ollama/"):]`, use `OllamaProvider(model_id)`.
   - Otherwise (no prefix): use `OllamaProvider(model)`.
   - If remote provider is chosen and no API key is found, raise `ProviderError("Missing API key for remote model. Set OPENROUTER_API_KEY or pass --api-key.")`.
</action>
