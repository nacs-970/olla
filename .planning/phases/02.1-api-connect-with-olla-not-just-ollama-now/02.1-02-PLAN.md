   - Update `run_loop` signature to accept `api_key: str | None = None` and `base_url: str | None = None`.
   - Before turn 1: instantiate `provider, resolved_model = get_provider(model=model, api_key=api_key, base_url=base_url)`.
   - Inside turn loop: replace `_call_model_for_loop(model, messages)` with `_stream_model_turn(provider, messages)`:
     - Iterates `chunk in provider.stream_chat(messages)`:
     - If `chunk.is_thought`, wrap output in dimmed style (ANSI `\033[2m` ... `\033[0m` or rich Console print) so the user sees thinking in real time.
     - If not thought, print text directly to stdout with `flush=True`.
     - Accumulate all text (thought + tool/answer) into `full_response`.
     - Catch `ProviderError` as well as network exceptions; display diagnostic via `_display(f"Model request failed: {error}")` and return `None` (graceful loop termination).
   - Filter out thinking tokens before tag evaluation: when extracting `<tool>` or `<final>`, do not match tags that occurred inside `<think>...</think>`.
2. Update `tests/test_loop.py` to mock `get_provider` and verify stream output and thinking formatting.
</action>
