- **D-09:** Configure 60s request timeout with automatic exponential retries on HTTP 429 and 5xx errors (up to 3 retries).

<research_summary>
## Summary

This phase extends `olla` beyond local Ollama to remote LLM APIs. By adhering to the OpenAI Chat Completions specification (`/chat/completions`) and focusing on OpenRouter as the standard aggregator, `olla` can query hundreds of remote models (Claude, GPT-4o, DeepSeek-R1, Llama 3) through a single unified protocol.

The standard client implementation uses `httpx>=0.27.0`. It provides synchronous HTTP streaming (`client.stream`), SSE line iteration (`iter_lines`), configurable connection pooling, and granular timeout management without bringing in heavyweight SDK dependencies.

The key technical requirement is real-time token streaming paired with stop sequence (`</args>`) enforcement. While OpenRouter accepts `"stop": ["</args>"]`, network chunking and provider variability can occasionally push partial stop tags down the wire. A sliding window buffer holding back at least `len("</args>")` (7 characters) guarantees that neither partial nor full stop tags leak into terminal display, while terminating the request stream as soon as the stop tag matches.

**Primary recommendation:** Establish `olla.providers` package with a clean `Provider` protocol, implement `OpenAICompatProvider` with `httpx.Client` stream handling and a 7-char sliding window buffer, and preserve `OllamaProvider` as the zero-config default.
</research_summary>

### Pattern 1: Sliding Window Stream Buffer for Stop Sequence
**What:** Maintain a tail buffer of length `len(stop_seq) - 1`. When a chunk arrives, append to buffer. If `stop_seq` appears in buffer, slice off before `stop_seq`, print remaining text, and close the stream. If not, yield characters that can no longer match `stop_seq`.
**When to use:** Whenever streaming tokens to terminal where an exact XML tag must stop generation.
**Example:**
```python
def stream_with_stop_buffer(stream_iterator, stop_seq: str = "</args>"):
    buffer = ""
    stop_len = len(stop_seq)
    for chunk in stream_iterator:
        buffer += chunk
        if stop_seq in buffer:
            head, _ = buffer.split(stop_seq, 1)
            yield head
            return
        if len(buffer) >= stop_len:
            flush_len = len(buffer) - (stop_len - 1)
            yield buffer[:flush_len]
            buffer = buffer[flush_len:]
    if buffer:
        yield buffer
```

### Pattern 2: Dimmed Reasoning Display
**What:** Parse `<think>` tags during streaming. Apply dimmed ANSI styling to tokens while inside the tag, and buffer until `</think>` completes.
**When to use:** DeepSeek-R1 or reasoning models on OpenRouter that stream thinking traces.

### Anti-Patterns to Avoid
- **Leaking `</args>` to terminal:** Leaking the stop tag causes terminal jitter and confuses users before tool confirmation.
- **Parsing `<tool>` inside `<think>`:** Some reasoning models deliberate: `I might call <tool>run_shell</tool>`, which is not a real invocation. Only parse tags outside thinking blocks.
- **Hardcoding OpenRouter model limits:** Hardcoding model context sizes breaks when OpenRouter updates context windows or introduces new models.

<dont_hand_roll>
## Don't Hand-Roll

| Problem | Don't Build | Use Instead | Why |
|---------|-------------|-------------|-----|
| HTTP connection pooling & keepalive | Raw `urllib` sockets | `httpx.Client` | Connection reuse dramatically lowers latency on multi-turn ReAct loops. |
| Exponential backoff | Ad-hoc sleep loops | Configured loop with `min(base * 2**attempt, max_delay) + jitter` | Prevents thundering herd and handles 429 Retry-After headers cleanly. |
| Server-Sent Events line decoding | Byte regex parsing | `response.iter_lines()` | Handles variable chunk boundaries, CR/LF differences, and UTF-8 splits across TCP packets. |
</dont_hand_roll>

<common_pitfalls>
## Common Pitfalls

### Pitfall 1: Multi-byte UTF-8 split across SSE chunks
**What goes wrong:** Decoding partial bytes throws `UnicodeDecodeError`.
**Why it happens:** HTTP streaming delivers chunks at arbitrary packet boundaries.
**How to avoid:** Use `httpx`'s text iterator `iter_lines()` which manages incremental text decoding automatically.

### Pitfall 2: OpenRouter HTTP 429 Rate Limiting
**What goes wrong:** Fast loops trigger transient rate limits on free or tier-1 endpoints.
**Why it happens:** ReAct agent calls models consecutively in short bursts.
**How to avoid:** Catch HTTP 429 status code, check `Retry-After` header, and retry with exponential backoff up to 3 times.

### Pitfall 3: Broken Provider Prefix Resolution
**What goes wrong:** `olla "task" --model qwen2.5:3b` breaks or tries to call OpenAI.
**Why it happens:** Naive prefix matching that doesn't default to Ollama when no known provider prefix is present.
**How to avoid:** If `--model` does not start with `openrouter/`, `openai/`, or other registered prefixes, route to `ollama`.
</common_pitfalls>

<code_examples>
## Code Examples

### OpenRouter Streaming Request with httpx
```python
import json
import httpx

def stream_openrouter_chat(
    api_key: str,
    model: str,
    messages: list[dict],
    base_url: str = "https://openrouter.ai/api/v1",
    stop: list[str] = ["</args>"],
    timeout: float = 60.0
):
    headers = {
        "Authorization": f"Bearer {api_key}",
        "HTTP-Referer": "https://github.com/olla/olla",
        "X-Title": "olla CLI Agent",
        "Content-Type": "application/json",
    }
    payload = {
        "model": model,
        "messages": messages,
        "stop": stop,
        "stream": True,
    }
    with httpx.Client(timeout=timeout) as client:
        with client.stream("POST", f"{base_url}/chat/completions", headers=headers, json=payload) as response:
            if response.status_code != 200:
                error_body = response.read().decode("utf-8", errors="replace")
                raise RuntimeError(f"OpenRouter error ({response.status_code}): {error_body}")
            for line in response.iter_lines():
                if not line.startswith("data: "):
                    continue
                data_str = line[6:].strip()
                if data_str == "[DONE]":
                    break
                chunk = json.loads(data_str)
                delta = chunk.get("choices", [{}])[0].get("delta", {}).get("content", "")
                if delta:
                    yield delta
```
