## Phase Goal

**As a** user running a multi-step olla task, **I want to** let the model store and explicitly recall short notes during one run, **so that** it can carry intermediate facts forward without re-deriving them.

Build the production remember→recall tracer and the complete bounded scratchpad contract for MEM-01.

Purpose: Prove the Phase 4 architecture end-to-end through the existing model protocol, parser, loop, terminal output, Observation history, and prompt before expanding edge coverage. The scratchpad remains an invocation-local standard-library object with no persistence or host side effects.

Output: `src/olla/tools/memory.py`, a working remember→recall→final loop path, exact adapter semantics, and focused automated tests.
</objective>

<interfaces>
The executor must preserve these existing contracts:

- `parse_response(content: str) -> dict` returns tool calls as `{"type": "tool", "tool": str, "args_raw": str}`. `write_file` already preserves opaque payloads; `remember` joins that preservation seam while `recall` retains the ordinary trimmed path.
- `ToolResult` is a `TypedDict(total=False)` with existing `content` and `error` fields. Memory success/status text uses `content`; malformed, missing, and limit failures use `error`.
- `run_loop(task, model, max_steps, system_prompt, yes=False, dry_run=False) -> None` owns invocation-local messages and repetition state. It must also own exactly one `Scratchpad`.
- Memory calls follow the existing no-confirm read-file branch for policy, but must select a non-empty explicit result before terminal/Observation rendering so a valid stored empty string never becomes `(no output)`.

Create these stable public contracts in `src/olla/tools/memory.py`:

- `MAX_VALUE_CHARS = 2_000`
- `MAX_KEYS = 32`
- `MAX_TOTAL_CHARS = 16_000`
- immutable `RememberCall` carrying `key: str` and `value: str`
- `parse_remember_args(args_raw: str) -> tuple[RememberCall | None, str | None]`
- `parse_recall_args(args_raw: str) -> tuple[str | None, str | None]`
- `Scratchpad.remember(call: RememberCall) -> ToolResult`
- `Scratchpad.recall(key: str) -> ToolResult`
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Model output -> parser/adapter | Untrusted model-controlled key/value text crosses into mutable in-process state. |
| One run_loop invocation -> next invocation | Notes must be discarded at return and must never cross the invocation boundary. |
| Memory result -> terminal/model history | Stored content can be disclosed only by explicit recall, never by remember or automatic injection. |
