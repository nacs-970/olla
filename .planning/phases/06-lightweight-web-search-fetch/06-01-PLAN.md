## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output -> `fetch_url` argument | The model chooses an arbitrary URL string with no host/scheme validation (D-02) |
| remote HTTP response -> olla process | Response bytes/HTML from an arbitrary, potentially hostile, third-party server are parsed and fed back into the model's context |
| web tool output -> subsequent tool-call trust state | `search_web`/`fetch_url` output can contain adversarial instructions; must not be treated as trusted user input by a later loop step |
