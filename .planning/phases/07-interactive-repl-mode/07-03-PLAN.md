<objective>
Implement REPL-03: proactive, token-budgeted rolling context trimming. Add `tiktoken`-based counting
against the provider's real context length, a summarize-and-replace digest mechanism that protects the
system prompt and the current in-progress turn, and — the single highest-severity item flagged by
research — an explicit decision that the digest preserves the existing untrusted-content trust boundary
rather than silently laundering it away.

Purpose: Long REPL sessions must not blow past `num_ctx`, must not crash on a `tiktoken` network hiccup,
and must not let content the model was told to distrust reappear as trusted-looking summary text.
Output: `src/olla/context_trim.py` (new); a single trim-check chokepoint inside `_stream_model_turn()`;
`repl.py` warms the encoder at startup.
</objective>

## Flagged Assumptions (spec-less edge probe, REPL-03)

The deterministic edge-probe engine returned REPL-03 as `category: "unclassified"` (no auto-detected
edge dimension) — per protocol this stays `unresolved`, not silently resolved. Manually reviewed
candidate edges and where each is addressed:
- **Trimming when history is already below threshold** — `should_trim()` is a pure threshold comparison;
  returns `False` and the chokepoint is a no-op (Task 1).
- **A single turn's own content alone exceeds the entire budget (untrimmable)** — `summarize_and_trim()`
  is a no-op when `messages[1:protected_from_index]` is empty, so an oversized in-progress turn is
  allowed to exceed budget rather than being force-trimmed into an invalid state (Task 1 behavior spec).
- **The summarization call itself fails (provider error)** — falls back to a placeholder eviction digest
  rather than raising or retrying indefinitely (Task 1 behavior spec).
- **`tiktoken` failing mid-session after a prior successful warm-up** (e.g. transient network loss on a
  cache-miss re-fetch) — `get_encoder()` caches `None` on failure so it fails the same way on every
  subsequent call rather than retrying per-call (Task 1 action).

This assumption set is carried forward for the executor/checker to confirm no other REPL-03 edge
dimension was missed — not assumed complete by this plan alone.
