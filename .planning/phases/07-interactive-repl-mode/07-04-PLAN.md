<objective>
Close the two gaps 07-VERIFICATION.md found in Phase 7: (1) `PromptSession` is constructed with
`multiline=False` and no supplementary key binding, so no keyboard path inserts a newline before Enter
submits — REPL-01's "multiline editing" clause is not actually deliverable; and (2) no test drives the
cross-turn negative case for the read-before-write staleness check (a file read in REPL turn 1, modified
externally, then written-without-re-reading in REPL turn 2 on the same shared `SessionState`) — the
positive case is tested, the negative case is only tested within a single `run_loop()` invocation.

Purpose: REQUIREMENTS.md and 07-02-SUMMARY.md currently claim REPL-01's multiline editing is complete and
07-01's cross-turn staleness prohibition is enforced; neither claim is actually test-proven as shipped.
This plan makes both claims true and test-proven, without touching anything else in the phase.
Output: `src/olla/repl.py` gains a real Alt+Enter-inserts-newline key binding (Enter still submits);
`tests/test_repl.py` gains a behavioral test proving it; `tests/test_loop.py` gains the missing cross-turn
negative staleness test.
</objective>
