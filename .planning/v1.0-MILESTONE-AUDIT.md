## 4. Cross-Phase Integration & E2E Flows

Integration checker subagent verified all inter-module contracts:
1. **Model Invocation & Streaming:**
   - Handles Ollama local endpoints and OpenAI-compatible remote endpoints (OpenRouter/OpenAI).
   - Dynamic context length resolution and exponential retry backoff on HTTP 429/5xx errors.
   - Stream buffer suppresses trailing `</args>` stop sequence from leaking to stdout.
   - Reasoning tokens enclosed in `<think>...</think>` tags are rendered with dimmed styling and stripped prior to tool parsing.
2. **Action Normalization & Gating:**
   - Single unified parser (`parse_response`) classifies outputs into `final`, `none`, `shell`, `read_file`, `write_file`, `remember`, `recall`, or `unknown`.
   - `safety.check()` enforces allowlist/blocklist rules with recursive unwrapping (`env`, `find -exec`, `sh/bash/zsh -c`).
   - Confirmation gates prompt before execution. Untrusted observations revoke `--yes` bypass to prevent indirect prompt injection attacks.
   - POSIX atomic writes guarantee race-free file modification and require prior read validation.
3. **Memory Lifecycle:**
   - `Scratchpad` initialized fresh per invocation; enforces 32-key, 2,000-char value, and 16,000-char total capacity limits.
   - Repetition guard normalizes memory actions and halts on repeated identical calls.

## 5. Technical Debt & Non-Blocking Items

1. **Phase 02 (safety.py):** `Decision` TypedDict uses `total=False` to retain Python 3.10 compatibility without `typing_extensions`. `check()` unconditionally sets `kind`. A future refactor can use a two-class inheritance split for tighter type checking.
2. **Phase 02 (test_safety.py):** Regression test reads source without explicit `encoding="utf-8"`, which could raise `UnicodeDecodeError` under strict `LC_ALL=C` non-UTF-8 locales. Passes on standard UTF-8 locales.
3. **Phase 04 (loop.py):** Telemetry reference to `scratchpad._data` was corrected to `scratchpad._values` to accurately report keys in `--debug` output.
